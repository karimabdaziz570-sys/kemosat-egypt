# KemoSat Egypt — Production Starter

هذه النسخة هي أول خطوة لتحويل التصميم إلى متجر فعلي. تم فصل الواجهة عن خادم API وقاعدة البيانات، مع إنشاء جداول المنتجات والعملاء والطلبات وبنود الطلبات.

## التشغيل محليًا
1. ثبّت Node.js 20 أو أحدث.
2. افتح الطرفية داخل مجلد المشروع.
3. نفّذ: `npm install`
4. انسخ `.env.example` إلى `.env` وعدّل القيم.
5. نفّذ: `npm start`
6. افتح: `http://localhost:3000`

## ما تم تجهيزه
- Express API.
- Helmet وCORS.
- SQLite كبداية عملية سهلة للنشر والاختبار.
- قاعدة بيانات للمنتجات والعملاء والطلبات.
- إنشاء الطلبات والتحقق من المخزون.
- حساب شحن أولي: القاهرة 60 ج.م، باقي المحافظات 100 ج.م.
- عدم وضع أسرار الدفع في الواجهة.

## قبل الإطلاق التجاري
- نقل قاعدة البيانات إلى PostgreSQL/MySQL عند الحاجة للتوسع.
- إضافة تسجيل دخول وصلاحيات للوحة الإدارة.
- ربط مزود دفع مصري فعلي وWebhooks للتحقق من الدفع.
- ربط شركة شحن/API فعلي.
- إضافة صور المنتجات ورفعها إلى تخزين مناسب.
- HTTPS ودومين.
- نسخ احتياطية ومراقبة وأمن إضافي.
- إضافة صفحات الخصوصية والشروط والاسترجاع.

## الدفع
خيارات InstaPay والمحافظ والبطاقات في الواجهة لا تعني أن الدفع أصبح متصلًا فعليًا. لا تضع مفاتيح سرية في `public/`. سيتم تنفيذ الربط الحقيقي بعد تحديد مزود الدفع والحسابات التجارية ومفاتيح API.
